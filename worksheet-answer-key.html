CODES — FORMAT & VERIFICATION
Each code has THREE parts: GRADE-IDENTITY-SCORE. Example: WAVE-S6KG-080
  WAVE / HAUN / HOCO / PROM  — grade tag (9 / 10 / 11 / 12)
  XXXX — 4-char hash of student’s name (use master list to verify)
  PPP — quiz score 000–100 (self-graded by the game)

To verify: Use code-master-list.html. Paste roster, get expected codes. Compare the first 9 chars (e.g., WAVE-S6KG). The last 3 chars are the student’s end-of-grade quiz score — the game graded it automatically. 5 questions per grade, each worth 20%.

PART 4 — REFLECTION
Open response. Grade for effort + game-specific evidence.

  3. Bus cost & class size: $1,750 / 40 seniors = $43.75 each. $1,750 / 20 seniors = $87.50 each. Same bus, fewer kids = more each pays. (FIXED cost spread over fewer people.)
  4. One thing learned: Good answers reference: margin, fixed vs. variable cost, demand curves, splitting cost across class size, opportunity cost.
🔍 HOW TO SPOT CHEATING
  1. Codes don’t start with right prefix (WAVE/HAUN/HOCO/PROM) ⇒ fake.
  2. 4-char suffix doesn’t match master list for their name ⇒ either they used a different name in the game, or they made it up.
  3. Q23 (skip paperwork) has a dollar amount ⇒ they didn’t actually play that path.
  4. Wrong character names (Terry/Bobby) ⇒ can’t Google — they didn’t play.
  5. Wrong specific numbers ($1,750 bus, $45 yearbook, 36 cars, +50% food) ⇒ copied a friend who guessed.
  6. Generic reflection answers with no game-specific terms ⇒ AI / copied.
  7. Only 1–2 codes filled in ⇒ only played some grades. Partial credit at your discretion.
